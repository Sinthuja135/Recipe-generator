# Leftover Recipe Generator

Full project including frontend (Vite + React) and backend (Express) that calls Anthropic Claude.

## Setup

### Frontend
1. Install and run:
```bash
cd vite-project
npm install
npm run dev
```

vercel integrated 
```bash
vercel dev
```

Open http://localhost:5173

Notes:
- Backend expects `ANTHROPIC_API_KEY` in server/.env
